# 업무현황판 데이터 분석 쿼리 모음

_데이터 출처: Power Apps 업무현황판 → Daily_DB를 CSV로 내려받아 SQLite에 적재_

> 공개 저장소용 안내: 실제 분석 **결과 수치·해석·조직 관련 제안은 사내 자료라 포함하지 않았다.**
> 여기에는 재현 가능한 **분석 방법과 SQL만** 남겼다. 쿼리 안의 인원명·프로젝트명은
> `사용자01`, `제품A`, `TF 프로젝트X` 같은 자리표시자로 바꿔 두었다.

---

## 1. 데이터 개요
- **주요 컬럼**: 작성일자, 작성자, 팀, 업무_계정, 프로젝트명, 작업시간
- **날짜 기준**: `Created`(만든 날짜)가 아니라 `작성일자` 기준. 비어 있으면 `만든 날짜`로 보정
- **전처리 규칙**
  - 주말(`strftime('%w')` 가 0, 6) 제외
  - `연차(반차)` / `교육` 제외
  - `TF` 중 특정 프로젝트(`TF 프로젝트X`)만 제외
  - `기타업무` 중 제품 인증·시험 관련 항목은 `제품개발(제품A)`로 재분류
  - 분석 대상에서 빼야 하는 인원(관리자·장기 부재자 등)은 `NOT IN (...)` 목록으로 제외
  - 동일 인물·일자 중복 기록은 합산

---

## 2. 분석 구조

### 2-1. 업무_계정별 / 월별 투입률
- 월별 투입률 = 해당 계정 총시간 ÷ 연구소 전체 투입시간 × 100 (월별 합 100%로 표준화)
- 쿼리: `monthly-input-rate-by-category.sql`, `monthly-input-rate-by-5-category*.sql`

### 2-2. 프로젝트별 / 월별 투입률
- 제외 항목을 뺀 잔여 프로젝트 집합 기준으로 월별 합 100%
- 총합_% = 프로젝트 총시간 ÷ 잔여 프로젝트 전체 총시간 × 100
- "총합_%"는 기간 누적 점유율, "평균_%"는 지속 투입 강도의 대표값
- 쿼리: `monthly-resource-utilization-rate-by-project*.sql`

### 2-3. 팀별 투입률 및 운영 효율
| 항목 | 정의 | 해석 포인트 |
|------|------|-------------|
| **기간_총시간** | 기간 내 실제 업무시간 합 | 절대 투입 규모 |
| **총합_%** | 전체 팀 중 해당 팀 비중 (합=100%) | 조직 내 상대적 기여도 |
| **가동률_%** | 실제 근무시간 ÷ (일별 고유인원 × 8h) | 과부하/여유 판단 |
| **고유_투입인원** | 작성자 수 (중복 제거) | 실제 참여 인원 규모 |
| **1인_평균시간** | 총 투입시간 ÷ 고유 인원 | 1인당 평균 업무량 |
| **분산도** | 고유 프로젝트 수 ÷ 고유 인원 | 1.0 이상이면 다중 프로젝트 병행 |

- 쿼리: `Team-by-team-deployment-rate-analysis.sql`, `monthly,task-based-and-project-based-utilization-rates.sql`

### 2-4. 팀별 업무일지 작성률 (신규)
앱의 대시보드 작성률(DashB_Screen)과 **같은 기준**으로 SQL에서 검증하기 위한 쿼리.

- 작성률 = 실제 작성 (작성자, 날짜) 수 ÷ (팀 인원 × 근무일수) × 100
- 근무일 = 평일 − 공휴일(`holidays` 테이블) − 오늘 이후 날짜
- 하루에 여러 건 써도 1로 셈 (시간 무관, "썼는지"만)
- 팀 귀속은 Daily_DB의 당시 팀이 아니라 UserInfo_DB의 현재 팀
- 쿼리: `weekly-writing-rate-by-team.sql`

### 2-5. 데이터 정리
- `extract-duplicate-data.sql`: 중복 행 추출
- `remove-duplicate-data.sql`: 중복 행 제거

## 3. DB 컬럼 설명 (집계 결과 테이블)
- **업무_계정_대분류**, **프로젝트명_소분류**
- **총_프로젝트시간**: 기간 합
- **총_표준용량**: Σ(일 참여자수 × 8), 같은 기간 공통 분모
- **총_투입률_표준화(%)** = 총_프로젝트시간 ÷ 총_표준용량 × 100
- **전체_고유_투입인원**: 기간 내 한 번이라도 참여한 인원
- **기간_1인_평균시간** = 총_프로젝트시간 ÷ 전체_고유_투입인원
- **월별_투입률_%**: `YYYY-MM_%` 형식, 각 월의 표준화 기준%
